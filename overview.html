Интеллектуальный анализатор колонок (Field Mapping) с автоматическим сопоставлением русских и английских названий полей.

🔑 Двухфакторная аутентификация (2FA)

Встроенный генератор TOTP (RFC 6238) с нативной генерацией QR-кодов в SVG без внешних облачных сервисов.

Встроенный веб-сервер и мобильный UI (Material 3 Dark)

📱 Адаптивный Mobile-First дизайн

Разработан строго по спецификациям Google Material Design 3 (Material You): скругления, Tonal Elevation, отсутствие жестких рамок.

📞 Интерактивные чипсы действий

Клик по внутреннему или мобильному телефону инициирует звонок или копирует номер с красивым всплывающим Toast-уведомлением.

🔒 Автономность без CDN

Все скрипты, стили и SVG-иконки внедрены в бинарник (Single Page Application). Работает в изолированной сети без доступа в Интернет.

⚡ Высокопроизводительный REST API

Эндпоинты /api/contacts и /api/status для интеграции с корпоративными IP-АТС (Asterisk, FreePBX) и другими ИС.

Соответствие требованиям 152-ФЗ РФ и Приказу ФСТЭК № 21

В программе реализованы обязательные организационно-технические меры защиты персональных данных при их обработке в информационных системах (ИСПДн до 1-го уровня защищенности включительно).

Состав модулей кодовой базы

Архитектура разделена на независимые, легко тестируемые модули без циклических зависимостей:

src/server.rs HTTPS & Web
Встроенный веб-сервер на GIO TLS, маршрутизатор REST API, генератор SPA интерфейса Material 3 Dark Theme, Rate Limiter.
src/audit.rs Безопасность
Журнал аудита событий безопасности 152-ФЗ с фиксацией IP, типа операции и строгими правами доступа 0600.
src/crypto.rs Криптография
Криптографические примитивы на базе 512-битной ARX-перестановки, генерация ключей и шифрование паролей БД.
src/totp.rs & qr.rs 2FA / TOTP
Генерация одноразовых паролей RFC 6238 и нативный рендеринг векторных SVG QR-кодов без внешних зависимостей.
src/db/wire.rs & libpq.rs База данных
Нативная реализация сетевого протокола PostgreSQL Wire Protocol на чистых сокетах и пул соединений с fallback кэшем.
src/field_mapping.rs Импорт CSV
Интеллектуальное сопоставление заголовков таблиц CSV со списком синонимов на русском и английском языках.
src/ui/window.rs GTK4 UI
Главное окно программы: AdwNavigationSplitView, быстрый поиск, горячие клавиши, выпадающие фильтры.
src/ui/settings_dialog.rs Настройки
Интерфейс управления параметрами: включение HTTPS, пути к TLS-сертификатам, генерация ключей, подключение к БД.
src/model.rs & storage.rs Модель данных
Структура Contact с поддержкой 152-ФЗ полей, сериализация в JSON и локальное энергонезависимое хранение.

Сборка, установка и эксплуатация

1. Установка готового Debian (.deb) пакета

Пакет содержит оптимизированный релизный бинарник, десктопный ярлык, масштабируемые SVG-иконки и скрипты инициализации каталогов аудита.

sudo dpkg -i corporate-contacts_1.0.0_amd64.deb

2. Запуск полного автономного тестирования (35 тестов)

cargo test --offline

3. Компиляция релизной версии

make release && make deb

4. Просмотр журнала аудита безопасности 152-ФЗ

sudo tail -f /var/log/corporate-contacts/audit.log
